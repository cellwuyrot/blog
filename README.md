# acoulbot.space — запуск и управление

Персональное портфолио Andy Coulbot: русская и английская версии, новости, интерактивный холст, «Визуал», страницы проектов, мастерская и SEO-основа. Python/Flask + SQLite. Публичная версия сайта формируется сервером; сборка интерактивных компонентов уже включена в архив.

## Быстрый запуск на компьютере

Нужен Python 3.10 или новее. Распакуйте архив и откройте терминал **в папке проекта**.

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py set-password
.\.venv\Scripts\python.exe app.py
```

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py set-password
.venv/bin/python app.py
```

При создании пароля введите дважды пароль из 12 или более символов. В терминале ввод не отображается — это нормально. Откройте **http://127.0.0.1:3011/**, вход в мастерскую — **http://127.0.0.1:3011/enter**. Остановка — `Ctrl+C`. Чтобы сменить пароль, выполните команду `app.py set-password` ещё раз. Не публикуйте пароль, `.env`, папку `data` или резервные копии.

Для локальной проверки не обязательно создавать `.env`. Если копируете `.env.example` в `.env` для настройки интеграций, на локальном HTTP установите `COOKIE_SECURE=0` и `TRUST_PROXY=0`: иначе вход не сохранится. При изменении `.env` перезапускайте сервер. `SITE_URL` задаёт **публичный адрес** для canonical и sitemap; в локальной копии они могут указывать на будущий домен — это нормально.

## Если обновляете предыдущую версию

1. Остановите приложение. Скопируйте **в безопасное место целиком** старые `data/` (включая `site.sqlite3`, `secret_key`, `uploads/`) и `.env`. Если вручную меняли исходники или статические файлы, отдельно сохраните и их: новый архив их заменит. Делайте резервную копию при остановленном приложении, чтобы не потерять изменения SQLite.
2. Разместите новую версию кода; верните старые `data/` и `.env`, не заменяя их демонстрационными данными. Если использовали внешнюю папку данных, укажите тот же `DATA_DIR` в окружении процесса. Сохраните зависимости и обновите их командой `pip install -r requirements.txt` в виртуальном окружении.
3. Перезапустите и проверьте вход, проекты, изображения и ссылки. Старые `/project/...` перенаправляются на `/ru/project/...`. Данные старого формата читаются без принудительного удаления или пересоздания. Пример новости со старым исходным slug `journal` распознаётся как новость; тип других записей можно поменять вручную в мастерской.

## Обновление холста и изображений

- В публикации добавьте основное и дополнительные изображения холста. В видимой области одновременно показывается не более одного экземпляра каждого уникального изображения; после ухода из вида оно может появиться снова на другом масштабе. Одинаковые файлы определяются по содержимому. Для проекта без изображения остаётся текстовая карточка. Колесо непрерывно меняет масштаб, перетаскивание перемещает холст.
- Обложка страницы, картинка выделенного раздела и изображения холста независимы. Режим «Целиком» сохраняет пропорции, прозрачность и не обрезает изображение; для режима «Заполнить» рекомендуются 1600 × 900 px, края могут обрезаться.
- Для фонового изображения можно задать цвет, размытие и затемнение и оценить их в небольшом предпросмотре. Полный предпросмотр открывает несохранённые данные в безопасном режиме без интерактивных скриптов; перед просмотром укажите корректный адрес записи. Старые настройки затемнения сохраняются, пока ползунок не изменён.
- Раздел «Медиа» показывает возможные неиспользуемые файлы, но не удаляет их: туда могут попасть ещё не сохранённые загрузки или файлы со внешними ссылками. Перед любыми ручными действиями обязательно проверьте использование и резервные копии.
- Для Discord задайте настоящую ссылку на профиль или приглашение в «Контактах». До этого ник отображается без ссылки. Не используйте один ник для создания предполагаемого адреса профиля.
- После одной минуты неподвижности указателя случайная пасхалка появляется только один раз за загрузку страницы. При настройке уменьшения движения и на устройствах без мыши она отключена.

## Мастерская

- `/enter` → введите установленный пароль. Во вкладке «Публикации» кнопка «Новая публикация» создаёт черновик. Выберите тип «Проект» или «Новость»: новости отображаются в верхней ленте, проекты — на холсте. В новости можно выбрать связанный проект; ссылка видна только когда он опубликован.
- Для публикации нужны название, категория и короткое описание **на обоих языках**. Если заполняете заголовок, текст или alt внутри элемента, заполните это поле на обоих языках. Черновик можно сохранить неполным. Для загруженных изображений в элементах перед публикацией нужны осмысленные alt-описания на обоих языках.
- Указывайте адрес из латинских букв, цифр и дефисов. Адреса должны быть уникальны для всех записей. Меняйте их осторожно: старые ссылки не перенаправляются автоматически.
- Добавляйте и переставляйте текст, изображения слева/справа, изображения на всю ширину и видео. Допустимы PNG, JPG, GIF, WebP, MP4 и WebM. Максимальный размер **всего запроса** — 150 МиБ; для больших видео лучше уменьшить файл. Файлы загружаются в `data/uploads/`, удаление записи само файлы не удаляет. Сохраняйте запись после загрузки.
- В «Публикациях» отдельно загружаются изображение проекта для холста и изображение выделенного раздела Connect или книги на главной. Для холста выберите «Целиком» (включая прозрачность) либо «Заполнить» (с возможной обрезкой). В Connect видео из элементов страницы имеет приоритет над изображением; без видео и изображения остаётся встроенная графика. Для книги без отдельного изображения используется обложка холста.
- «Специальный раздел» Connect или Книга показывает выбранный проект отдельно на главной. Если добавить видео в элемент Connect, оно появится в его разделе. «Предпросмотр без сохранения» открывает текущую форму (в том числе черновик) после входа; он закрыт от индексации.
- «Тексты сайта»: выберите раздел, отредактируйте русский и английский тексты, нажмите «Сохранить тексты раздела». Так редактируются первый экран, навигация, подвал, «Обо мне», политика конфиденциальности, подписи блоков и основные SEO-тексты. Сохранение сразу публикует оба языка; если в другой группе остались несохранённые изменения, сохраните и её. Название acoulbot и некоторые технические обозначения остаются частью оформления. Тексты самих проектов и новостей редактируются в «Публикациях».
- «Сейчас в работе»: в «Текстах сайта» выберите одноимённый раздел и заполните короткую заметку на двух языках. Чтобы скрыть строку, очистите её на обоих языках и сохраните.
- Перед загрузкой оптимизируйте размер фотографий: сервер сохраняет оригиналы и не создаёт миниатюры автоматически. Это особенно важно для мобильной скорости.
- «Фото · Обо мне»: загрузите фотографии, добавьте alt на обоих языках и сохраните. Первое изображение используется в блоке главной, все — на странице «Обо мне». Можно изменить порядок, точку кадрирования превью и включить подписи. Двухъязычные подписи необязательны.
- «Визуал»: добавьте до 60 собственных снимков (включая GIF), задайте порядок и кадрирование, alt на двух языках и при желании подписи. Переключатель включает или отключает показ подписей; пустой раздел показывает нейтральную подсказку, а весь раздел можно скрыть. На компьютере изображения реагируют на курсор, по нажатию открывается оригинал целиком; на телефоне ленту можно листать и открывать касанием. В открытом просмотре доступны кнопки и стрелки клавиатуры, закрытие — кнопкой, Esc или нажатием на фон.
- «Контакты»: меняйте адреса Telegram, почты и Connect; пустая строка скрывает ссылку. Подписи ссылок находятся в «Тексты сайта → Общие элементы». При изменении почты отдельно обновите контактный текст политики конфиденциальности.
- «Spotify»: плейлист настраивается ссылкой. Демонстрационные материалы Signal и новость можно заменить или удалить; фотографии в «Визуал» и «Обо мне» по умолчанию не подставляются. Для реальных проектов добавьте собственные обложки и подтверждённые подробности.
- На ПК перемещайте холст перетаскиванием и масштабируйте колёсиком; для обычной вертикальной прокрутки ведите курсор за пределами холста. На мобильном нажмите «Исследовать касанием»: двигайте одним пальцем и меняйте масштаб двумя, затем завершите режим для прокрутки страницы. Без JavaScript доступны простые ссылки на проекты; при настройке уменьшения движения анимация упрощается.

## Публикация на сервере: порт 3011

Архив подходит для Git, но **данные в Git не хранятся**. Установите Python, Git, nginx и используйте виртуальное окружение. Пример для Linux (замените пользователя и пути):

```bash
cd /srv/acoulbot
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
# Отредактируйте .env и установите публичный SITE_URL и параметры ниже.
.venv/bin/python app.py set-password
.venv/bin/gunicorn --bind 127.0.0.1:3011 --workers 1 --timeout 120 app:app
```

Запускайте Gunicorn через systemd или другой supervisor. Файлы данных должны переживать деплой и иметь права только для пользователя службы. Если хотите хранить их вне репозитория, укажите `DATA_DIR=/var/lib/acoulbot` **в окружении службы** до запуска любых команд, включая установку пароля; одной строки в `.env` для `DATA_DIR` недостаточно. Регулярно сохраняйте копии БД, `uploads/`, `secret_key` и `.env` вне публичного доступа. Ограничение попыток входа в приложении хранится в памяти одного процесса; при нескольких процессах/инстансах настройте дополнительный rate limit на прокси и мониторинг.

Пример Nginx после настройки DNS и выпуска TLS-сертификата (замените пути сертификатов на свои):

```nginx
server {
    listen 80;
    server_name acoulbot.space;
    return 301 https://$host$request_uri;
}
server {
    listen 443 ssl;
    server_name acoulbot.space;
    ssl_certificate /etc/letsencrypt/live/acoulbot.space/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/acoulbot.space/privkey.pem;
    client_max_body_size 150m;
    location / {
        proxy_pass http://127.0.0.1:3011;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_read_timeout 120s;
    }
}
```

Для HTTPS настройте `.env`: `SITE_URL=https://acoulbot.space`, `COOKIE_SECURE=1`, `TRUST_PROXY=1` **только если доступ к приложению ограничен доверенным nginx**, который перезаписывает указанные заголовки. Примените конфигурацию после `nginx -t`. Настройка DNS, сертификата, резервного копирования, обновлений и мониторинга остаётся за владельцем сервера.

## Поиск и аналитика

Реализованы серверная разметка, локализованные title/description, canonical и hreflang, Open Graph, Schema.org Person/WebSite, favicon, `robots.txt`, динамический `sitemap.xml`, отдельные страницы About и 404, RSS новостей `/ru/feed.xml` и `/en/feed.xml`. Индексируются опубликованные записи; черновики не попадают в sitemap/RSS. SEO не гарантирует индексацию или позиции, скорость зависит от реального сервера и загруженных медиа.

После публикации:

1. В Google Search Console добавьте и подтвердите сайт; в Яндекс Вебмастере сделайте то же. Подтверждение доступно через DNS или метатег: для метатега вставьте **значение** (без всего HTML-тега) в `GOOGLE_SITE_VERIFICATION` или `YANDEX_SITE_VERIFICATION` в `.env`, затем перезапустите приложение.
2. В обоих сервисах вручную отправьте `https://acoulbot.space/sitemap.xml` и проверяйте охват, ошибки, индексацию. Автоматически подключения и отправки за вас не выполняются.
3. По желанию укажите в `.env` `GA_MEASUREMENT_ID=G-...` и числовой `YANDEX_METRIKA_ID=...`, перезапустите. Скрипты аналитики подключаются после согласия посетителя на дополнительные cookie. GTM не обязателен и не добавлен, чтобы избежать дублирования счётчиков. Проверяйте сбор в интерфейсах соответствующих сервисов.
4. Open Graph по умолчанию использует `static/og-default.png`, а публикация с обложкой использует её. Укажите настоящие профили и актуальные материалы; неподтверждённый URL YouTube не придуман. `llms.txt` намеренно не добавлен: он необязателен.

Небольшое окно cookie позволяет выбрать только необходимые или разрешить дополнительные; выбор можно изменить в подвале. При отказе встроенный Spotify и счётчики не загружаются. Страница `/ru/privacy` — **начальный шаблон**, а не юридическое заключение: перед запуском уточните оператора, фактические цели, инструменты, сроки хранения, способы связи и требования законодательства/регионов и обновите русский и английский тексты. Сторонние ссылки и сервисы регулируются также их собственными правилами.

## Spotify: что слушаю сейчас

Плейлист и статус — разные функции. Для плейлиста достаточно ссылки в мастерской и согласия посетителя. Для статуса создайте приложение в Spotify Developer Dashboard; в настройках разрешённых redirect URI укажите точный адрес `https://acoulbot.space/api/spotify/callback`. В `.env` укажите `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, `SPOTIFY_REDIRECT_URI` и перезапустите приложение, затем в мастерской нажмите «Подключить Spotify» и авторизуйте **свой** аккаунт. Доступ и ограничения API зависят от действующих правил Spotify. Секреты и refresh token хранятся на сервере; если трек не играет, индикатор скрыт. OAuth и реальный аккаунт необходимо проверить самостоятельно после настройки.

## Исходники компонентов

Небольшая пасхалка на устройствах с мышью срабатывает один раз за загрузку страницы после минуты неподвижности курсора; при системной настройке уменьшения движения отключена.

В `frontend/` находятся адаптированные компоненты, предоставленные для проекта, включая магнитную карусель «Визуал». Если редактируете их, нужны Node.js и npm:

```bash
npm ci
npm run build
```

Готовый `static/components.js` уже входит в проект. Проверьте права на использование исходных компонентов перед публикацией. Лицензии зависимостей и шрифтов лежат в `licenses/`, `FONT-LICENSE.txt` и `INTER-LICENSE.txt`.

## Автоматические серверные проверки

Запустите `.venv/bin/python -m unittest discover -s tests` (Windows: `.venv\Scripts\python.exe -m unittest discover -s tests`). Тесты используют временную базу и не изменяют ваши данные. Для полноценной проверки визуального вида, мобильных жестов и сторонних интеграций нужен браузер и собственные аккаунты.
